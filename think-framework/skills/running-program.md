# Running Program Guide

## Goal example
Run 5 km in under 30 minutes (pace ≈ 6:00 / km).

## Weekly structure (beginner–intermediate)
- 3 run days + 1 optional easy shakeout.
- Keep at least one full rest or cross-training day.

### Sample week
1. Easy run 20–30 min (conversational pace).
2. Intervals: 6–8 × 400 m hard / 90 s walk or jog.
3. Long easy run 35–45 min.
4. Optional: 15–20 min very easy jog or walk.

## Progression
- Increase weekly distance by ≤10%.
- Add interval volume before adding race-pace volume.
- Every 4th week, reduce volume ~20% (deload).

## Form cues
- Cadence near 170–180 steps/min if comfortable.
- Soft landing under the hips; avoid overstriding.
- Relax shoulders and hands.

## Injury notes
- Knee or shin pain → cut intensity first, then volume.
- Prefer soft surfaces for easy days when recovering.
- Strength work (squats, hinge, calf raises) 1–2× / week supports running goals.
